# 🚀 Запуск сервера

## Запуск
Дважды кликни на файл:
```
start_server.bat
```

Откроется окно с сообщением:
```
======================================================================
BDS Scraper Server
======================================================================
Сервер запущен на порту 8000
Откройте в браузере: http://localhost:8000
```

## Проверка статуса
Если не уверен, запущен ли сервер:
```
check_server.bat
```

## Остановка
```
stop_server.bat
```
или нажми `Ctrl+C` в окне сервера

---

## Если не работает:

### 1. Проверь порт
```powershell
netstat -ano | findstr ":8000" | findstr "LISTENING"
```

Должна быть строка типа:
```
TCP    0.0.0.0:8000           0.0.0.0:0              LISTENING       12345
```

### 2. Проверь файл статуса
Если сервер запущен, в папке будет файл `.server_status` с содержимым:
```
RUNNING|8000|12345
```

### 3. Проверь логи
После запуска через `start_server.bat` все ошибки будут видны в окне консоли.

### 4. Убей все процессы Python
Если порт занят другим процессом:
```powershell
taskkill /F /IM python.exe
```
