# 🔑 Установка OpenAI API ключа

## ✅ Способ 1: Через `.env` файл (РЕКОМЕНДУЕТСЯ)

**Преимущества:**
- Безопасно (файл в `.gitignore`, не попадет в Git)
- Удобно (один раз настроил - работает)
- Работает автоматически при запуске сервера

**Шаги:**

1. **Получите API ключ:**
   - Зайдите на https://platform.openai.com/api-keys
   - Нажмите **"Create new secret key"**
   - Скопируйте ключ (начинается с `sk-...`)

2. **Откройте файл `.env`** в корне проекта

3. **Замените плейсхолдер на ваш ключ:**
   ```
   OPENAI_API_KEY=sk-ваш-настоящий-ключ-сюда
   ```

4. **Сохраните файл**

5. **Готово!** Просто запустите `start_server.bat` или `start_server.ps1`

## 🔧 Способ 2: Системные переменные Windows (постоянно)

**Преимущества:**
- Работает для всех приложений
- Не нужен файл `.env`

**Шаги:**

1. Нажмите `Win + Pause/Break` → **Дополнительные параметры системы**
2. **Переменные среды** → **Создать** (в разделе "Переменные пользователя")
3. Имя: `OPENAI_API_KEY`
4. Значение: `sk-ваш-ключ`
5. **ОК** → Перезапустите терминал
6. Проверка: `echo $env:OPENAI_API_KEY` в PowerShell

---

## ⚡ Способ 3: Временно в PowerShell

**Для одной сессии терминала:**

```powershell
$env:OPENAI_API_KEY="sk-ваш-ключ-здесь"
python server.py
```

---

## 📋 Проверка установки

**PowerShell:**
```powershell
$env:OPENAI_API_KEY
```

**CMD:**
```cmd
echo %OPENAI_API_KEY%
```

Должен вывести ваш ключ, начинающийся с `sk-`

---

## 🛠️ Troubleshooting

**Ошибка:** `OPENAI_API_KEY не установлен`
- Проверьте правильность имени переменной (регистр важен!)
- Перезапустите сервер после установки
- Убедитесь что `.env` файл находится в корне проекта

**Ошибка:** `Invalid API key`
- Проверьте правильность ключа на https://platform.openai.com/api-keys
- Убедитесь что скопировали весь ключ без пробелов

**Ошибка:** `Rate limit exceeded`
- Подождите минуту
- Проверьте баланс на https://platform.openai.com/usage

## 🚀 Запуск

После установки ключа просто запустите:

**Windows:**
```cmd
start_server.bat
```

**PowerShell:**
```powershell
.\start_server.ps1
```

Или напрямую:
```cmd
python server.py
```

Откройте `index.html` в браузере и тестируйте AI рекомендации!
