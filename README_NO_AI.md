# 🎯 BDS Scraper - Система рекомендаций БЕЗ AI

## ✅ Что изменилось?

Система рекомендаций ставок **полностью переписана** на чистый Python без использования OpenAI API.

### Преимущества:

✅ **Бесплатно** - не нужен API ключ OpenAI  
✅ **Быстро** - расчет за миллисекунды вместо 10-15 секунд  
✅ **Прозрачно** - понятный алгоритм без "черного ящика"  
✅ **Надежно** - не зависит от внешних сервисов  
✅ **Точно** - такая же методика, как раньше с AI  

---

## 📊 Как работает алгоритм

### 1. Фильтрация аналогов

Из базы выбираются лоты с:
- **Точным** совпадением модели
- Год ±1
- Пробег ±50%
- Оценка ±1

### 2. Расчет коэффициентов

Для каждого аналога:
```
Коэффициент = Финальная_цена / Стартовая_цена
```

Выбросы (коэффициент > 1.5) удаляются.

### 3. Статистический анализ

Рассчитываются перцентили: p25, p30, p40, p50, p60, p70

### 4. Выбор коэффициента

| Условие | Перцентиль | Диапазон |
|---------|------------|----------|
| Оценка ≥7, пробег ≤5k | p60 | [p50, p70] |
| Оценка 6, пробег ≤5k | p50 | [p40, p60] |
| Оценка 5, пробег ≤5k | p40 | [p30, p50] |
| Оценка 5-6, пробег 5-15k | p40 | [p30, p50] |
| Оценка <5 или пробег >15k | p30 | [p25, p40] |
| Аналогов <5 | 1.15 | [1.10, 1.20] |

### 5. Расчет ставок

```python
recommended_bid_min = start_price × диапазон[0]
recommended_bid_optimal = start_price × коэффициент
recommended_bid_max = start_price × диапазон[1]
```

## 💡 Пример использования в коде

```python
from recommendation_engine import calculate_recommendation

# Целевой лот
target_lot = {
    'Наименование': 'Ducati DESERT X',
    'Год': '2023',
    'Пробег': '4 471',
    'Оценка': '5',
    'Стартовая цена (₽)': '1 173 506'
}

# Исторические данные (из БД)
all_lots = get_all_lots_from_db()

# Расчет рекомендации
result = calculate_recommendation(target_lot, all_lots)

print(f"Оптимальная ставка: {result['recommended_bid_optimal']:,.0f} ₽")
print(f"Коэффициент: {result['chosen_coefficient']}")
print(f"Аналогов: {result['comparables_used']}")
```

## 🎓 Методика

Система использует **статистический анализ исторических торгов**:

1. Находит аналогичные лоты
2. Рассчитывает коэффициенты роста цены
3. Выбирает подходящий перцентиль на основе характеристик
4. Рассчитывает рекомендуемый диапазон ставок

**Цель**: рекомендовать ставку, которая дает ~40-60% шанс выиграть лот с прибылью.
