# 🏍️ BDS Scraper - Полное руководство

Веб-приложение для парсинга аукционов мотоциклов + AI рекомендации по ставкам

## 🚀 Быстрый старт

### 1. Установите зависимости (если ещё не установлены):
```bash
pip install -r requirements.txt
```

### 2. Настройте OpenAI API ключ:

**Получите ключ:**
- Зайдите на https://platform.openai.com/
- Создайте API ключ

**Установите в Windows:**
```bash
set OPENAI_API_KEY=sk-ваш-ключ-здесь
```

**Проверьте:**
```bash
echo %OPENAI_API_KEY%
```

### 3. Запустите сервер:
```bash
python server.py
```

### 4. Откройте `index.html` в браузере

## ✨ Возможности приложения

### 📊 Статистика базы данных
- Показывает общее количество лотов
- Последние 10 добавленных записей
- Загружается автоматически при открытии

### 🤖 AI Рекомендация ставки (НОВОЕ!)

**Что делает:**
- Анализирует исторические данные из БД
- Находит аналогичные лоты (модель, год, пробег, оценка)
- Рассчитывает коэффициенты продаж
- Выдаёт 3 ставки: минимум, оптимум, максимум

**Как использовать:**
1. Заполните форму:
   ```
   Модель: Yamaha XT690Z TENERE 700
   Год: 2025
   Пробег: 25
   Оценка: 7
   Стартовая цена: 1296163
   ```
2. Нажмите "Получить рекомендацию AI"
3. Подождите ~10-15 секунд
4. Получите детальный анализ

**Алгоритм AI:**
- Фильтрует аналоги по модели
- Учитывает год ±1-2
- Близкий пробег
- Оценка ≥ целевая-1
- Рассчитывает перцентили (p60, p70, p75, p80, p85)
- Выбирает коэффициент в зависимости от состояния:
  - Новый (пробег ≤2000км) + оценка 7 → p80
  - Новый + оценка 5 → p65
  - Средний пробег → p70

### 🔍 Парсинг новых лотов

**Что делает:**
- Парсит все страницы по URL
- Автоматически проверяет дубликаты
- Добавляет только новые лоты в БД
- Показывает статистику парсинга

**Как использовать:**
1. Вставьте URL:
   ```
   https://cemeco.ru/stat/ducati/desert-x/
   https://cemeco.ru/stat/yamaha/xt690z-tenere-700/
   https://cemeco.ru/stat/ktm/890-adventure/
   ```
2. Нажмите "Запустить парсинг"
3. Ждите (может занять несколько минут)
4. Видите результаты:
   - Найдено
   - Добавлено
   - Дубликаты
   - Ошибки

## ❓ FAQ

**Q: Сервер не запускается**
A: Убедитесь что находитесь в директории проекта `c:\CURSOR\BDS - Scraper`

**Q: AI не работает / ошибка API key**
A: Установите ключ: `set OPENAI_API_KEY=sk-...` и перезапустите сервер

**Q: Страница показывает "Сервер не запущен"**
A: Запустите `python server.py` и обновите страницу (F5)

**Q: Дубликаты всё равно добавляются**
A: Проверка идёт по: Дата аукциона + Аукционный дом + Номер лота

**Q: AI долго думает**
A: Нормально, обработка 1000 лотов + GPT-4o занимает 10-15 сек
