# BDS Scraper - Веб-приложение

Простое локальное веб-приложение для парсинга аукционных лотов с cemeco.ru

## 🚀 Быстрый старт

### 1. Запустите сервер:
```bash
python server.py
```

### 2. Откройте файл в браузере:
```
index.html
```
Просто откройте файл `index.html` в вашем браузере (двойной клик по файлу).

## ✨ Функции

- **📊 Статистика базы данных** - показывает общее количество лотов и последние добавленные
- **🔍 Парсинг новых лотов** - вставьте URL страницы, и приложение спарсит все лоты
- **✅ Автопроверка дубликатов** - не добавляет лоты, которые уже есть в базе
- **📈 Результаты в реальном времени** - видите сколько найдено, добавлено, пропущено

## 📝 Как использовать

1. **Запустите сервер** (`python server.py`)
2. **Откройте** `index.html` в браузере
3. **Вставьте URL**, например:
   ```
   https://cemeco.ru/stat/ducati/desert-x/
   https://cemeco.ru/stat/yamaha/xt690z-tenere-700/
   https://cemeco.ru/stat/ktm/890-adventure/
   ```
4. **Нажмите** "Запустить парсинг"
5. **Ждите** - приложение спарсит все страницы и покажет результаты

## 🗄️ База данных

Используется существующая база: `lots_multi_20251017_142157.db`

## 🛠️ Технологии

- **Backend**: Python + http.server (без Flask!)
- **Frontend**: HTML + CSS + JavaScript
- **Parsing**: BeautifulSoup4 + Requests
- **Database**: SQLite

## ⚙️ Требования

```bash
pip install requests beautifulsoup4
```

## 🔧 Порты
