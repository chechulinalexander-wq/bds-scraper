# Парсер мотоаукционов CEMECO.RU

Набор скриптов для сбора и анализа данных о мотоциклах с японских аукционов через сайт cemeco.ru

## Созданные файлы

### Скрипты парсинга

1. **scraper.py** - Базовый парсер для одной модели
   - Парсит Yamaha XT690Z TENERE 700 (с 2023 года)
   - Сохраняет в Excel и SQLite

2. **scraper_multi.py** - Мультимодельный парсер ⭐
   - Парсит несколько моделей одновременно
   - Объединяет с существующими данными
   - Создает бекап старой таблицы
   - Текущие модели:
     - Yamaha XT690Z TENERE 700 (с 2023 года)
     - Aprilia TOUAREG 660
     - KTM 890 ADVENTURE
     - KTM 890 ADVENTURE R

### Утилиты

3. **excel_to_sqlite.py** - Конвертер Excel → SQLite
   ```bash
   python excel_to_sqlite.py <файл.xlsx>
   ```

4. **check_db.py** - Проверка содержимого базы данных
   ```bash
   python check_db.py <файл.db>
   ```

5. **check_tables.py** - Детальная проверка таблиц в базе

## Структура данных

### Колонки в таблице

- **Наименование** - Бренд и модель мотоцикла
- **Дата аукциона** - Дата проведения аукциона
- **Аукционный дом** - Название аукционного дома (BDS Kantou, AUCNET и т.д.)
- **Номер лота** - Номер лота на аукционе
- **Год** - Год выпуска мотоцикла
- **Пробег** - Пробег в км
- **Объем** - Объем двигателя в сс
- **Оценка** - Оценка состояния (0-10)
- **Статус аукциона** - Статус проведения аукциона
- **Статус** - Статус продажи (Продан)
- **Цена (¥)** - Конечная цена в йенах
- **Цена (₽)** - Конечная цена в рублях
- **Стартовая цена (¥)** - Стартовая цена в йенах
- **Стартовая цена (₽)** - Стартовая цена в рублях
- **URL карточки** - Ссылка на карточку лота

## Использование

### Быстрый старт

1. Парсинг всех моделей:
```bash
python scraper_multi.py
```

2. Проверка базы:
```bash
python check_tables.py
```

### Работа с базой данных

**Подключение:**
```python
import sqlite3
conn = sqlite3.connect('lots_multi_20251017_142157.db')
```

**Примеры запросов:**

```sql
-- Все KTM
SELECT * FROM lots WHERE "Наименование" LIKE 'KTM%';

-- Лоты 2024 года с пробегом до 1000 км
SELECT * FROM lots WHERE "Год" = 2024 AND CAST(REPLACE("Пробег", ' км', '') AS INTEGER) < 1000;

-- Средняя цена по моделям
SELECT "Наименование", AVG(CAST(REPLACE(REPLACE("Цена (₽)", ' ', ''), '₽', '') AS INTEGER)) as avg_price
FROM lots 
GROUP BY "Наименование";

-- Топ 10 самых дорогих лотов
SELECT "Наименование", "Год", "Пробег", "Цена (₽)"
FROM lots
ORDER BY CAST(REPLACE(REPLACE("Цена (₽)", ' ', ''), '₽', '') AS INTEGER) DESC
LIMIT 10;
```

## Добавление новых моделей

Отредактируйте `scraper_multi.py`, раздел `models_config`:

```python
models_config = [
    {
        'name': 'Название модели',
        'url': 'https://cemeco.ru/stat/brand/model/',
        'params': ''  # или '?f-st=0&f-name=&f-year-from=2023'
    }
]
```
