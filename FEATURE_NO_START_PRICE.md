# Функция: Рекомендации без стартовой цены

## Описание
Добавлен альтернативный алгоритм расчета рекомендаций для случаев, когда стартовая цена лота отсутствует.

## Изменения

### recommendation_engine.py
Добавлены две новые функции:

1. **`filter_comparables_by_final_price()`**
   - Фильтрует аналоги по тем же критериям (модель, год ±1, пробег ±50%, оценка ±1)
   - Но требует только финальную цену (не нужна стартовая цена)

2. **`calculate_recommendation_without_start_price()`**
   - Альтернативный алгоритм расчета рекомендаций
   - Использует прямые финальные цены из аналогичных лотов
   - Выбирает перцентиль на основе качества лота (оценка + пробег)
   - Возвращает рекомендации в том же формате + флаг `alternative_algorithm: true`

### Логика работы

#### Стандартный алгоритм (стартовая цена есть):
```
1. Найти аналоги
2. Вычислить коэффициенты: финальная_цена / стартовая_цена
3. Выбрать перцентиль коэффициентов на основе качества
4. Рекомендация = стартовая_цена × коэффициент
```

#### Альтернативный алгоритм (стартовой цены нет):
```
1. Найти аналоги с финальными ценами
2. Собрать финальные цены
3. Выбрать перцентиль финальных цен на основе качества
4. Рекомендация = перцентиль финальных цен
```

### Выбор перцентиля

Для обоих алгоритмов используется одинаковая логика:

| Оценка | Пробег     | Перцентиль |
|--------|------------|------------|
| ≥7     | ≤5000 км   | p60        |
| ≥6     | любой      | p50        |
| ≥5     | любой      | p40        |
| <5     | любой      | p30        |

### index.html
- Поле "Стартовая цена" теперь **опциональное**
- Добавлена обработка результатов альтернативного алгоритма
- При `alternative_algorithm: true` показываются:
  - "Алгоритм: Альтернативный (без стартовой цены)"
  - "Перцентиль финальных цен"
  - "Медиана финальных цен"
- Предупреждения о пониженной точности

## Предупреждения

При использовании альтернативного алгоритма система выдает:
- "ВНИМАНИЕ: Стартовая цена отсутствует - рекомендация основана только на финальных ценах аналогов"
- "Точность оценки может быть ниже обычной"
- Дополнительные предупреждения о малом количестве аналогов, волатильности и т.д.

## Примеры

### Пример 1: Без стартовой цены, есть аналоги
```python
test_lot = {
    'Наименование': 'Ducati DESERT X',
    'Год': '2023',
    'Пробег': '4 471',
    'Оценка': '6',
    'Стартовая цена (₽)': ''  # ПУСТАЯ
}

result = calculate_recommendation(test_lot, all_lots)
# Результат:
# {
#     'recommended_bid_min': 1260000,
#     'recommended_bid_optimal': 1300000,
#     'recommended_bid_max': 1320000,
#     'alternative_algorithm': True,
#     'comparables_used': 5,
#     'percentile_used': 'p50',
#     'warnings': [
#         'ВНИМАНИЕ: Стартовая цена отсутствует...',
#         'Точность оценки может быть ниже обычной'
#     ]
# }
```

### Пример 2: Без стартовой цены, нет аналогов
```python
result = calculate_recommendation(test_lot, [])

```
