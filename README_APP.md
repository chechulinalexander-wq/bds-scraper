# BDS Scraper - Веб-приложение

Локальное веб-приложение для парсинга аукционных лотов с сайта cemeco.ru

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите приложение:
```bash
python app.py
```

3. Откройте в браузере:
```
http://localhost:5000
```

## Функции

- **Просмотр статистики**: Показывает общее количество лотов в базе и последние добавленные записи
- **Парсинг новых лотов**: Вставьте URL страницы с лотами, и приложение автоматически спарсит все карточки
- **Проверка дубликатов**: Приложение автоматически проверяет наличие лотов в базе по дате, аукционному дому и номеру лота
- **Результаты парсинга**: После парсинга отображается статистика - сколько найдено, добавлено, пропущено дубликатов

## Примеры URL

```
https://cemeco.ru/stat/ducati/desert-x/
https://cemeco.ru/stat/yamaha/xt690z-tenere-700/
https://cemeco.ru/stat/ktm/890-adventure/
```

## База данных

Приложение использует существующую базу данных `lots_multi_20251017_142157.db`

Структура таблицы `lots`:
- Наименование
- Дата аукциона
- Аукционный дом
- Номер лота
- Год
- Пробег
- Объем
- Оценка
- Статус аукциона
- Статус
- Цена (¥)
- Цена (₽)
- Стартовая цена (¥)
- Стартовая цена (₽)
- URL карточки

## Технологии

- **Backend**: Python + Flask
- **Frontend**: HTML + CSS + JavaScript
- **Database**: SQLite
- **Parsing**: BeautifulSoup4 + Requests
